### About these repositories

Every project here is a **curated excerpt**, not the full original codebase —
real client/employer names, credentials, and connection strings are never
included, and each repo's own README explains exactly what was left out and
why (usually: the parts that would let someone clone a working copy, or that
belong to a real deployed product). If you'd like to see more of any of these
in an interview setting, I'm happy to walk through the full codebase live.
